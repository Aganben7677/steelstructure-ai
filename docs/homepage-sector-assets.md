## Processing

Sharp: resize to maximum 1920 / 960 / 240 pixels wide, without enlargement;
WebP quality 82 / 80 / 75. No visual retouching. CSS object-fit applies responsive
display cropping. Keep source attribution and the relevant license with reused
photographs; CC BY-SA derivatives retain the original share-alike license.

## Behavior

7-second crossfade; previous / next, seven sector choices, pause / play and touch
swipe. Manual selection pauses. Hover, keyboard focus, hidden tabs and an
offscreen hero hold autoplay. Reduced-motion preference disables autoplay by
default and removes transitions. Play is an explicit override. Images decode
before the visible slide changes; a failed next image leaves the current photo
visible and pauses. English / Chinese category titles follow the site language.
